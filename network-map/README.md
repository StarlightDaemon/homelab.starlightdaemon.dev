# Network Map Workspace

This directory is the default workspace for a more accurate network map that accompanies the homelab site without changing the current live site.

## Scope

Use this area for:

- topology notes
- source-of-truth inventory
- draft diagrams
- exported assets
- future map prototypes

## Do Not Touch

Unless the operator explicitly says otherwise, do not change:

- `../index.html`
- `../css/homelab.css`
- `../js/homelab.js`
- `../assets/`

## Suggested Workflow

1. Record the real network layout in `topology-inventory.md`.
2. Add draft assets or map source files in this directory.
3. Keep integration separate until the operator asks for live-site changes.
